# Universal Unlock DEX

## Key
`12947-ffmax`

## Features
- Unlimited days
- Unlimited time
- Universal login bypass
- Works with most login apps

## Download
1. Go to **Actions** tab
2. Click latest successful run
3. Download **universal-unlock-dex** artifact

## Apply via MT Manager
1. Open target APK in MT Manager
2. Tap APK → View → classes.dex
3. Menu → Dex Editor Plus → Add → DEX file
4. Select `universal_unlock.dex`
5. Save → Sign → Install
6. Enter key `12947-ffmax`
